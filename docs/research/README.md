# Research

This directory contains time-stamped evidence for specification and
architecture decisions. Research is not normative. Research from before the
2026-08-23 simplification reset can describe removed product behavior.

Source-service reviews identify exact file paths and current behavior. They
also state which behavior is service-specific and which behavior can
move to LLM Router. Do not change a source service during discovery.

- [Source-service review](source-services-2026-08.md) is pre-reset evidence.
  Its hosted-frame, Router-hosted agent, shared-tool, and OpenAI-compatibility
  recommendations are not current requirements.
- [Draft adapter baseline](adapter-baseline-2026-08.md) is pre-reset evidence.
  Its source paths remain useful, but its proposed adapter and shared-tool
  matrix is not the accepted first adapter set.
- [Foundation verification](foundation-verification-2026-08-13.md) is
  historical evidence for the removed contract set.

The accepted current product source is the
[service simplification decision](../interviews/service-simplification-2026-08-23.md).
