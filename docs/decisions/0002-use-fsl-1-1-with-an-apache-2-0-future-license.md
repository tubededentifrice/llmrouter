# Use FSL 1.1 with an Apache 2.0 future license

- Status: accepted and applied
- Date: 2026-08-12
- Decision owner: user

## Context

The owner wants source availability and broad future use. The owner also wants
to limit some competing production use for a fixed initial period.

## Decision

Use the Functional Source License, Version 1.1, ALv2 Future License
(`FSL-1.1-ALv2`). Each released version changes to Apache License 2.0 on the
second anniversary of the date that version becomes available.

Use the canonical license text without change. Use `Copyright 2026
tubededentifrice` as the notice.

## Alternatives

- Apache License 2.0 immediately has no initial competing-use limit.
- MIT has no explicit patent terms or initial competing-use limit.
- AGPL-3.0 requires source sharing for modified network services.

## Consequences

The project is source-available and is not open source during each version's
initial FSL period. Release records must keep the availability date for each
version.

## Review conditions

Review this decision if the licensor or future-license policy changes.
